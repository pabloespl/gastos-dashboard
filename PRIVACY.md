# Privacy Policy

Gastos Dashboard is a personal application used to process financial transaction
emails and account statements from the application's authorized Gmail account.

The application accesses Gmail data only for the purpose of identifying and
processing transaction-related emails and attachments.

Data is not sold, shared, or disclosed to third parties.

The application is intended for personal use by the account owner.

For questions regarding this privacy policy, contact the developer through the
contact information provided in the application's OAuth consent screen.
